Módulo 1

Visual Studio Code

El editor donde sucede toda la magia.

¿Qué es VS Code?

Visual Studio Code es un editor de código gratuito y open source desarrollado por Microsoft. Es la herramienta más popular del mundo entre desarrolladores (más del 70% lo usan). Lo importante para ti:

  • 📝 Edita cualquier archivo de texto (código, markdown, JSON, CSV…).
  • 🧩 Tiene extensiones que le agregan capacidades (Git, AI, debugging, etc.).
  • 💬 GitHub Copilot Chat vive aquí — lo abres y conversas con AI sin salir del editor.
  • 🆓 Es 100% gratis, sin limitaciones.
ℹ️ ¿VS Code o Visual Studio?
Son diferentes. Visual Studio (sin "Code") es un IDE pesado para .NET/C++. VS Code es liviano, multilenguaje y multiplataforma. Para esta clase usamos VS Code.

Instalación paso a paso

Descarga el instalador

Ve a code.visualstudio.com y haz clic en el botón azul de descarga. Detectará tu sistema operativo automáticamente.

Ejecuta el instalador

En Windows, marca las opciones:

  • ✅ Agregar "Abrir con Code" al menú contextual del Explorador
  • ✅ Registrar Code como editor para tipos de archivo compatibles
  • ✅ Agregar a PATH

Abre VS Code

  • Sidebar: contenido de la vista seleccionada.
  • Editor (centro): donde editas tus archivos.

Módulo 2

GitHub

La plataforma donde vive el código del mundo.

¿Qué es GitHub?

GitHub es una plataforma propiedad de Microsoft donde los desarrolladores alojan, versionan y colaboran en proyectos de código. Piensa en ella como un Google Drive especializado para código, con superpoderes:

  • 🌳 Versionamiento: cada cambio queda registrado. Puedes volver atrás en el tiempo.
  • 👥 Colaboración: varias personas pueden trabajar en el mismo proyecto sin pisarse.
  • 📦 Repositorios públicos: millones de proyectos gratis para usar y aprender.
  • 🤖 GitHub Copilot: la AI vive aquí.

Git vs GitHub — ¿es lo mismo?

No.

  • Git es la tecnología de control de versiones (la creó Linus Torvalds, el de Linux). Funciona en tu computadora.
  • GitHub es una plataforma web que usa Git como base, agregándole interfaz, colaboración, etc.

Analogía: Git es el motor, GitHub es el carro completo.

Crear tu cuenta de GitHub

Ve a github.com/signup

Abre github.com/signup en tu navegador.

Ingresa tu correo

Usa un correo personal (no laboral). Te llegará un código de verificación.

Crea tu username

Tu username es público y único. Sugerencias: nombre-apellido, nombre1234. Evita espacios y caracteres especiales.

Verifica que no eres robot

GitHub te pedirá un captcha. Resuélvelo.

Los 3 modos del Chat

1. Ask (preguntar)

Modo conversacional. Le preguntas algo y te responde con texto/código que tú copias.

Explícame qué hace este bloque de código como si tuviera 10 años.

2. Edit (editar)

Le pides cambios y Copilot edita los archivos directamente. Tú revisas y aceptas o rechazas.

Agrega validación de email al formulario de registro y muestra el error en rojo.

3. Agent (agente)

Copilot trabaja como un agente autónomo: lee múltiples archivos, ejecuta comandos en terminal, instala dependencias, escribe pruebas, todo en una sola tarea.

Crea un script en Python que lea ejemplos/metricas-equipo.csv, calcule el promedio de velocity por sprint y genere un reporte Excel con un gráfico de barras.
⚡ Atajo clave

Módulo 4

Conectar y cambiar modelos de AI

Una sola interfaz, múltiples cerebros.

¿Qué es un "modelo" de AI?

Un modelo es el "cerebro" detrás del chat. Distintos modelos tienen diferentes fortalezas:

  • GPT-5 (OpenAI): muy fuerte en razonamiento general y código.
  • Claude Sonnet 4.5 (Anthropic): excelente para tareas largas, análisis, escritura.
  • Gemini Pro (Google): bueno con contexto muy grande (libros enteros).
  • o1 / o3 (OpenAI): razonamiento profundo, ideal para problemas matemáticos.
💡 Lo mejor de Copilot
No tienes que pagar suscripciones a OpenAI, Anthropic y Google por separado. Con una sola suscripción a Copilot Pro (~$10/mes) accedes a todos.

Cómo cambiar de modelo en VS Code

Abre el chat

Presiona Ctrl+Alt+I o haz clic en el ícono de Copilot en la Activity Bar.

Localiza el selector de modelo

En la barra inferior de la caja de chat verás un pequeño botón con el nombre del modelo actual (ej. GPT-5).

Haz clic y elige otro modelo

Se abre un menú con los modelos disponibles según tu plan. Selecciona el que quieras.

El cambio aplica inmediatamente

Tu siguiente mensaje irá al modelo nuevo. Puedes cambiar cuantas veces quieras dentro de la misma conversación.

¿Cuándo usar cada modelo?

TareaModelo sugerido
Escribir/refactorizar códigoGPT-5 o Claude Sonnet
Documentos largos (PRDs, RFCs)Claude Sonnet
Analizar repositorios grandesGemini Pro (mucho contexto)
Problemas matemáticos / lógica complejao1 / o3
Conversación rápida / brainstormingGPT-5 (rápido y versátil)

Conexión a modelos personalizados (avanzado)

Copilot también te deja usar tu propia clave de API de OpenAI, Azure OpenAI o Anthropic. Útil si tu empresa ya paga acceso por su lado:

  1. En VS Code, abre Settings (Ctrl+,).
  2. Busca: copilot byok (Bring Your Own Key).
  3. Pega tu API key.
⚠️ Costos al usar tu propia key
Cuando usas tu propia API key, los costos los paga tu cuenta directamente con el proveedor (OpenAI, Anthropic, etc.), no GitHub. Revisa precios antes.

Módulo 5

Repos públicos, Skills y Agentes

Personaliza Copilot con conocimiento de la comunidad.

¿Qué son skills y agentes?

📦

Skill

Un archivo SKILL.md con instrucciones específicas para una tarea. Copilot lo lee cuando la conversación toca ese tema.

🤖

Agente (chat mode)

Un "modo" de chat con personalidad propia, herramientas restringidas y conocimiento previo. Tú lo activas cuando lo necesitas.

📜

copilot-instructions.md

Reglas globales que aplican a TODAS las conversaciones dentro de un proyecto.

Abre el repo en GitHub

Clic en el botón verde "<> Code"

Se abre un menú.

Clic en "Download ZIP"

Clic derecho → "Extraer aquí". Luego: VS Code → Archivo → Abrir carpeta y selecciona la carpeta descomprimida.

Estructura de una skill (formato simple)

Una skill es solo una carpeta con un archivo SKILL.md:

skills/
└── plan-sprint/
    └── SKILL.md

Dentro de SKILL.md:

---
name: plan-sprint
description: "Planifica un sprint con capacidad, selección de
historias y mapeo de riesgos. Úsala cuando el usuario quiera
preparar un sprint planning."
---

# Planificación de Sprint

## Contexto
Eres un facilitador de Scrum experimentado...

## Instrucciones
1. Estima la capacidad del equipo...
2. Selecciona historias del backlog...
3. Identifica riesgos...

Cómo Copilot encuentra y usa las skills

Cuando tienes esta carpeta abierta en VS Code y la activación de skills personalizadas habilitada, Copilot:

  1. Lee el archivo .github/copilot-instructions.md automáticamente.
  2. Tiene visibilidad de los archivos SKILL.md en skills/.
  3. Cuando tu pregunta coincide con la descripción de una skill, la usa.
💡 Tip
Si quieres forzar que Copilot use una skill específica, ábrela en el editor antes de preguntar o menciónala explícitamente: "usando la skill plan-sprint, ayúdame con..."

Modo agente personalizado (.chatmode.md)

VS Code te permite crear "modos de chat" personalizados. Mira el archivo:

agents/gerente-desarrollo.chatmode.md

Lo activas desde el chat de Copilot:

  1. Abre Copilot Chat (Ctrl+Alt+I).
  2. Clic en el selector de modo (donde dice "Ask" / "Edit" / "Agent").
  3. Elige el modo personalizado (aparece con su nombre).

Módulo 6

Generar Excel y PowerPoint con AI

Reportes ejecutivos sin tocar Office.

El truco

Copilot no genera archivos Excel o PPTX directamente — pero genera código Python que sí lo hace. Las librerías que usamos:

  • openpyxl → archivos .xlsx con formato, fórmulas y gráficos.
  • python-pptx → archivos .pptx con texto, tablas, imágenes y formato.
  • pandas → manipular datos (opcional pero útil).

Configuración inicial (una sola vez)

# Abre la terminal en VS Code (Ctrl+`) y ejecuta:
pip install openpyxl python-pptx pandas

# Verifica:
python -c "import openpyxl, pptx, pandas; print('Todo listo')"

Ejemplo 1: Reporte Excel de métricas del equipo

Tenemos un archivo de ejemplo: ejemplos/metricas-equipo.csv. Vamos a generarle un reporte ejecutivo.

Abre el archivo ejemplos/metricas-equipo.csv y crea un script Python que: 1. Lea los datos con pandas 2. Calcule promedio de velocity, throughput y lead time por equipo 3. Genere un archivo Excel "reporte-equipos.xlsx" con: - Hoja "Resumen" con los promedios formateados - Hoja "Detalle" con todos los datos - Un gráfico de barras de velocity por equipo - Encabezados en azul Microsoft (#0078D4) con texto blanco

Cuando Copilot genere el script:

  1. Lo guarda en un archivo .py (te avisa la ruta).
  2. Lo ejecutas con python nombre-del-script.py.
  3. El archivo .xlsx aparece en la carpeta del proyecto. Doble clic y se abre en Excel.

Ejemplo 2: Presentación ejecutiva

Genera una presentación PowerPoint "review-trimestral.pptx" con: - Portada con título "Review Q2 — Equipo de Plataforma" y subtítulo con la fecha de hoy - Slide de KPIs: 4 cuadros con velocity, throughput, lead time y deployment frequency - Slide con bullet points de los principales logros del trimestre (déjalos como placeholders) - Slide de riesgos identificados (tabla de 3 columnas: Riesgo, Impacto, Mitigación) - Slide de cierre con próximos pasos Usa colores corporativos azul Microsoft.

Patrón general (prompt reutilizable)

Para cualquier reporte, sigue esta estructura de prompt:

Crea un script Python que genere [Excel/PowerPoint] con:

1. ENTRADA: [archivo CSV / datos hardcoded / API]
2. PROCESAMIENTO: [qué cálculos / agrupaciones]
3. SALIDA: [nombre del archivo]
4. ESTRUCTURA: [hojas/slides y qué contiene cada una]
5. FORMATO: [colores, fuentes, estilo]
6. DESTINATARIO: [a quién va, para ajustar tono]
✅ Ventaja enorme
Una vez que tienes el script, lo puedes ejecutar cada mes/semana con datos nuevos. Reportes automatizados sin tocar Excel manualmente.

Ejercicio práctico

  1. Abre el archivo ejemplos/metricas-equipo.csv.
  2. Usa el primer prompt de ejemplo en Copilot Chat (modo Agent).
  3. Ejecuta el script generado.
  4. Abre el Excel resultante.
  5. Pídele a Copilot que cambie el gráfico a un line chart.
Módulo 7

Analizar archivos existentes (Excel, PowerPoint y PDF)

Convierte cualquier archivo que te llegue en insights accionables.

El escenario típico

Como gerente recibes archivos todo el día: el Excel de presupuesto del VP, el deck del trimestre pasado, el PDF de 80 páginas del contrato con un proveedor. La pregunta no es "¿qué dice?" sino "¿qué hago con esto?". La AI puede leerlos en segundos y darte resumen, riesgos y próximos pasos.

Las librerías que vamos a usar

Tipo de archivoExtensiónLibrería PythonCuándo usarla
Excel moderno.xlsxopenpyxl / pandasLo más común. pandas es más cómodo para análisis tabular.
Excel viejo.xlsxlrd==1.2.0 o convertir a .xlsxSi el archivo es de hace más de 10 años.
PowerPoint.pptxpython-pptxExtrae texto, tablas y notas del orador.
PDF con texto.pdfpypdf o pdfplumberpdfplumber es mejor cuando hay tablas.
PDF escaneado.pdfpytesseract + pdf2imageRequiere OCR. Más lento, pero salva PDFs que son imágenes.

Configuración inicial

# Una sola vez, en la terminal de VS Code (Ctrl+`):
pip install openpyxl pandas python-pptx pypdf pdfplumber

# Solo si vas a procesar PDFs escaneados (imagen):
pip install pytesseract pdf2image
# Además tienes que instalar Tesseract en tu máquina:
# Windows: https://github.com/UB-Mannheim/tesseract/wiki

El patrón general: extraer → analizar → actuar

1. Extraer

Copilot genera un script Python que abre el archivo y vuelca su contenido a texto/tablas legibles.

2. Analizar

No te quedes en el dump crudo. Pídele a Copilot que sintetice: TL;DR de 3 líneas, tabla de datos clave, riesgos detectados, preguntas abiertas.

3. Actuar

Encadena con otra skill: genera un Excel comparativo, un PPTX resumen, o el correo ejecutivo para tu staff.

Ejemplo 1: "¿Qué dice este Excel?"

Imagina que tu VP te mandó presupuesto-q2.xlsx y quieres entenderlo rápido.

Analiza el archivo presupuesto-q2.xlsx usando la skill analizar-archivos-existentes. Quiero: 1. Resumen de qué hojas tiene y qué contiene cada una. 2. Totales clave (presupuesto total, gastado, disponible). 3. Banderas rojas: ¿hay categorías sobregiradas? ¿fechas vencidas? 4. Qué preguntas le devuelvo al VP.

Ejemplo 2: "¿Qué dijimos el trimestre pasado?"

Lee el archivo review-q1.pptx, extáeme: - KPIs del trimestre con sus valores - Riesgos identificados (tabla con riesgo, impacto, mitigación) - Las notas del orador de cada slide Después, pásame un markdown con todo eso estructurado para que pueda compararlo con el Q2 actual.

Ejemplo 3: "Sácame lo importante de este contrato PDF"

Extrae el contenido de contrato-proveedor.pdf y dame: - SLAs comprometidos (uptime, tiempos de respuesta) - Penalidades por incumplimiento - Fechas críticas (vencimientos, renovaciones, revisiones) - Cláusulas de terminación anticipada - Quien firma por cada parte Formato: tabla resumen + lista de riesgos para mi legal.

Ejemplo 4: Comparar varios archivos

Tienes 5 reportes de status semanal en PPTX y quieres ver la evolución.

Tengo en la carpeta reports/ cinco archivos: status-semana-01.pptx hasta status-semana-05.pptx. Genera un script que: 1. Lea los 5 y extraiga la tabla de riesgos de cada uno. 2. Detecte qué riesgos se repiten y cuáles son nuevos. 3. Construya un Excel "evolución-riesgos.xlsx" con una columna por semana y una fila por riesgo, con ✅ si estaba activo. Usa las skills analizar-archivos-existentes y generar-reporte-excel.

Qué siempre revisar (checklist mental)

En un Excel ejecutivoEn un deck PPTXEn un PDF de negocio
  • ¿Hay hojas ocultas?
  • ¿Los totales cuadran?
  • ¿Hay valores hardcoded donde deberían ser fórmulas?
  • ¿Fechas mal parseadas?
  • Portada: título, período, autor
  • Números grandes = KPIs
  • Tablas suelen tener riesgos / owners
  • Notas del orador: oro puro
  • SLAs y penalidades
  • Fechas críticas
  • Owners / firmantes
  • Moneda y unidades (¿USD o MXN? ¿con IVA?)
⚠️ Privacidad de datos
Si el archivo trae datos personales (correos, salarios, nombres de clientes), recuerda que el modelo en la nube ve el contenido. Para casos sensibles, usa un modelo on-prem o anonimiza el archivo antes de analizarlo.
💡 Tip de productividad
Si vas a analizar el mismo tipo de archivo cada semana (ej. el reporte semanal de tu equipo), pídele a Copilot que guarde el script en scripts/analizar-status-semanal.py. La próxima vez solo lo ejecutas con el archivo nuevo.

Módulo 8

Casos de uso para Gerentes de Desarrollo y Product Managers

Donde la AI realmente te devuelve horas a la semana. Las skills aplican a ambos roles — cada SKILL.md distingue el matiz por audiencia cuando es relevante.

1. Planificación de sprints

Skill: plan-sprint

Pega tu backlog (incluso solo títulos), tu velocity histórica y tu capacidad. Copilot te arma el plan de sprint con dependencias y riesgos.

Mi equipo tiene 6 ingenieros. Velocity promedio: 45 puntos. La próxima quincena: Juan tiene 3 días de PTO, Ana está medio tiempo. Backlog priorizado: - [P0] Migración auth (13 pts) - [P0] Bug pago duplicado (5 pts) - [P1] Dashboard admin (8 pts) - [P1] Refactor de cache (8 pts) - [P2] Mejoras UX onboarding (5 pts) Plan el próximo sprint usando la skill plan-sprint.

2. Retrospectivas

Skill: retro-equipo

Le das contexto del sprint y te diseña la retrospectiva con un marco apropiado (4Ls, Sailboat, Start-Stop-Continue) y preguntas guía.

3. Reuniones 1:1

Skill: prep-one-on-one

Le pasas notas previas del reporte directo y temas pendientes, y te arma la agenda.

Tengo 1:1 mañana con Carlos. Historial: - Sprint pasado entregó tarde la API de pagos - Hace 2 semanas dijo que quería liderar un proyecto - En el survey marcó "no me siento valorado" Prepárame agenda usando la skill prep-one-on-one.

4. Reportes ejecutivos mensuales

Skills: generar-reporte-excel + generar-presentacion-pptx

Combinas datos y obtienes Excel + PPTX listos para tu staff o leadership.

5. Métricas DORA al liderazgo

Skill: metricas-dora

Las 4 métricas DORA traducidas a lenguaje ejecutivo con benchmarks de industria.

6. Code review más rápido

Skill: revisar-pr

Pegas el diff de un PR y Copilot te ayuda a:

  • Identificar issues de seguridad / performance.
  • Sugerir mejoras de legibilidad.
  • Escribir el comentario de approval o request-changes.

7. Onboarding de nuevo ingeniero

Skill: onboarding-30-60-90

Genera un plan de 30/60/90 días personalizado al rol, seniority y stack de tu equipo.

8. Conversaciones técnicas con tu equipo

Agente: Gerente de Desarrollo

Modo personalizado para discutir tradeoffs técnicos, RFCs, arquitectura, sin perder el lente de gestión (riesgo, time-to-market, equipo).

9. Comunicar un incidente productivo en vivo

Skill: comunicado-incidente

Durante un outage genera en paralelo: status page público, email a clientes afectados, mensaje a leadership y update al canal interno de respuesta. Cada uno con el tono y formato correcto, listo para pegar.

Tenemos un incidente: el endpoint /pay devuelve 500 desde las 10:30am. Afecta ~30% de los usuarios de México. ETA mitigación: 30-45 min. Genera los 4 comunicados usando la skill comunicado-incidente.

10. Status semanal a tu jefe / stakeholders

Skill: reporte-status-semanal

El "viernes de status" estandarizado: TL;DR, logros, en progreso, riesgos, ayuda necesaria y próxima semana. Mismo formato cada vez — menos tiempo, más credibilidad.

11. Postmortem REAL de un incidente

Skill: postmortem-incidente

Después del incidente: timeline minuto a minuto, análisis de causa raíz con 5 Whys, action items SMART y cultura blameless. No confundir con la skill postmortem global, que es pre-mortem de planes futuros.

12. Preparar una conversación difícil

Skill: conversacion-dificil

Feedback negativo, despido, decir "no" a un stakeholder, conflicto en el equipo. Usa el framework SBI (Situation-Behavior-Impact), te da script de apertura, anticipa reacciones y prepara el post-mortem de la conversación.

Tengo que dar feedback negativo a María. Lleva 3 sprints entregando tarde, no comunica blockers a tiempo, y en el último 1:1 se puso a la defensiva. Prepárame la conversación usando la skill conversacion-dificil.

13. Presentar a leadership (QBR, headcount, roadmap)

Skill: prep-presentacion-leadership

Memo de 1 página, 3 talking points anclados, las 10 preguntas que te van a hacer con respuestas listas, trampas políticas a manejar, y qué NO decir. Ideal para QBRs, requests de headcount, roadmap reviews y post-incidente con C-level.

Tengo presentación el miércoles con el VP de Eng y el CFO. Voy a pedir 3 ingenieros más para Q3. Audiencia: VP Eng (mi jefe, ya alineado), CFO (escéptico de costos), Head of Product (necesita mi roadmap). Prepárame usando la skill prep-presentacion-leadership.
